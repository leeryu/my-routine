# My Routine

GitHub Pages 공개용 단일 웹앱을 소스 분리한 버전입니다.

## 구조

```text
index.html
css/style.css
js/app.js
```

## 배포

1. 저장소 루트에 위 파일/폴더를 그대로 업로드합니다.
2. GitHub Settings > Pages에서 Branch를 main, Folder를 /root로 설정합니다.
3. 생성된 GitHub Pages URL로 접속합니다.

## 보안

- 외부 API 호출 없음
- API Key 없음
- 브라우저 localStorage에만 개인 기록 저장
- 공개 저장소 업로드 가능 버전
